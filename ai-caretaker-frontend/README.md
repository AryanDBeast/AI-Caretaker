# AI Caretaker — Caregiver Dashboard

Next.js + TypeScript dashboard where caregivers sign in and review their patients' conversation history, emergency events, and medication mentions.

```bash
npm install
NEXT_PUBLIC_BACKEND_URL=http://localhost:8000 npm run dev
```

Then open http://localhost:3000. All data comes from the FastAPI backend in `../ai-caretaker-backend`. See the [root README](../README.md) for the full system.
